# 라이선스

공통 코드와 SDK는 MIT, 공통 글꼴은 해당 OFL과 출처 manifest를 보존한다. 직접 만든 game의 SVG 예제 그림은 CC0-1.0으로 제공한다. 공통 묶음의 출처와 해시는 common-bundle.lock.json에 있다.

공통 캠프 배경과 메뉴 SVG는 `game-foundation`의 CC0-1.0 예제 그림이다. `GodotGooglePlayBilling`과 StoreKit 2의 MIT 라이선스 및 Firebase iOS SDK의 NOTICES는 소스와 내보낸 앱에 보존한다.

Poing AdMob 5.1.0의 MIT와 Firebase NOTICES를 포함한 네이티브 라이선스는 `godot/data/licenses`에 보존하고 내보내기에 포함한다. 원본과 적용한 통합 변경은 `native/dependencies.lock.json`에 고정한다.
