# 라이선스

공통 코드와 SDK는 MIT, 공통 글꼴은 해당 OFL과 출처 manifest를 보존한다. 직접 만든 game의 SVG 예제 그림은 CC0-1.0으로 제공한다. 공통 묶음의 출처와 해시는 common-bundle.lock.json에 있다.

네이티브 AdMob, Google Play Billing과 StoreKit 2는 MIT다. 배포 원본과 Firebase NOTICES를 `godot/data/licenses`에 보존하고 내보내기에 포함한다. 출처와 고정 해시는 `native/dependencies.lock.json` 및 `native/SOURCE.md`에 기록한다.
