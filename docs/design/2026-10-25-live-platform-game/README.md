# 검토 대기 설계

[설계와 제안 값](design.md), [테스트 계획](test-plan.json), [가로형 시안](ui-concepts.html)을 함께 검토한다. 실제 플랫폼 구현과 상품 등록은 아직 시작하지 않았다.

시안은 A 모험 캠프, B 탐험 지도, C 별빛 기지다. 레포 루트를 로컬 HTTP 서버로 열면 시안 선택과 메뉴 흐름을 확인할 수 있다. 캡처는1280x720과568x320에서 확인했다. 시안 버튼은 실제 계정이나 결제를 실행하지 않는다.

새 기능 목록의 ui_landscape와 platform_end_to_end는 구현 때 inventory에 추가할 예정이며 현재 등록된 실행 증거가 아니다. 기기 승인, 실제 native 지급과 운영 서비스 배포 검수를 이 계획 파일의 dev 통과로 대체하지 않는다.
