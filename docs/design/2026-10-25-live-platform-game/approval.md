# 승인 기록

- 승인 대상: 설계 및 테스트 계획 커밋 `0d2cbe5e614cc4497c8af8cb7a2752533d2c6456`.
- 근거: 이 대화에서 시안과 상품 및 연동 설계를 제안한 뒤 사용자가 `승인`으로 답했다.
- 화면: 추천안 A 모험 캠프.
- 상품: `starter_test_ticket_1` 소모품과 `starter_badge` 비소모품. 각각 미국 USD 0.99, 한국 KRW 1,500. 테스트 결제수단만 사용한다.
- 환경: 플랫폼 `starter-game`, Firebase `seorilabs-starter-game`, 서울 리전. 기존 앱 이름과 마켓 식별자는 유지한다.
- 버전: 앱 v1.1.0. SDK 공개 API 확장이 필요한 경우 SDK v1.1.0.
- 실행: L3 개발 환경 전체 회귀, 독립 기능 및 화면 검수 3회. 플랫폼과 백오피스의 승인 범위 운영 변경, Play 내부 테스트와 TestFlight 내부 그룹까지.
- 이번 범위는 현재 공통 플랫폼 기능 전체다. 친구와 길드, 신규 랭킹 및 푸시 기능 추가는 포함하지 않는다.
- 기기 사용과 법적 계약 수락은 승인하지 않았다.

확정된 방향과 구성요소는 같은 범위에서 다시 선택받지 않는다. 실제 미실행과 공급자 차단은 통과로 기록하지 않는다.
