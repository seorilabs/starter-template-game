# Markets

시장별 원장은 이 폴더에서 관리한다.

## 원칙

- 콘솔 값은 문서와 repo-local config에 반영한다.
- 모르는 값은 `확정 필요`로 유지한다.
- 심사 제출과 production promotion은 deployment approval 이후만 수행한다.

## Steam (PC)

Steam 마켓 원장은 아직 없다. 첫 Steam 출시 후보가 생기면 이 폴더에 Steamworks 콘솔 값을 기록하는 문서를 만든다. 그 전까지 PC 게임의 설계 요구(수익화 규칙, 심사와 공시, 스토어 자산 규격, Steam Deck)는 에이전트 스킬 문서 `game-planning-production/references/platform-pc-steam.md`를, 엔진 준비(export preset, 입력, 창, 저장 위치)는 `godot-game/references/pc-desktop.md`를 따른다. 출시 작업은 Steamworks 등록 단계에서 멈춘다.
